# DevShelf

DevShelf est une application modulaire et performante conçue pour centraliser, organiser et exploiter des ressources techniques et créatives. Ce projet démontre une maîtrise complète du cycle de développement, allant de la conception de l'interface utilisateur jusqu'au traitement bas niveau haute performance.

## Architecture du Projet

Le projet est structuré sous la forme d'un monorepo pour séparer clairement les différentes briques technologiques :

- `design/` : Maquettes, wireframes et chartes graphiques (UI/UX).
- `frontend/` : Interface web interactive et soignée.
- `backend-python/` : API REST robuste gérant la logique métier et les données (FastAPI).
- `rust-core/` : Module hautement optimisé pour les calculs intensifs ou le traitement de données (Rust).

## Stack Technique

- **Frontend :** React / Next.js, Tailwind CSS
- **Backend :** Python (FastAPI)
- **Performance :** Rust
- **Design :** Figma
